# Patagônia — Diário de Expedição

Roteiro de viagem pela Patagônia em formato de site: um diário de expedição do Chile à Argentina, de Punta Arenas a El Chaltén e volta, com paradas, custos por etapa, links de mapa e uma trilha de carimbos para marcar o que já foi cumprido.

**Site publicado:** https://claude.ai/code/artifact/2a928c9a-c2c7-4732-aba3-ae8a6a051cdd

## O que tem aqui

- [index.html](index.html) — a página completa do roteiro, em um único arquivo (HTML + CSS + JS), sem dependências externas. As fotos de cada etapa vêm do Wikimedia Commons e estão embutidas diretamente no arquivo.

Para ver o roteiro, basta abrir o `index.html` em qualquer navegador — não precisa de servidor.

## Etapas cobertas

1. Punta Arenas (Fuerte Bulnes, Parque del Estrecho)
2. Puerto Natales — chegada
3. Torres del Paine (Cuernos, Lago Grey, caiaque, cavalgada)
4. Puerto Natales → El Calafate
5. El Calafate — chegada
6. Parque Nacional Los Glaciares (Perito Moreno, minitrekking)
7. Estancia Nibepo Aike
8. El Calafate → El Chaltén
9. El Chaltén — chegada
10. Laguna de los Tres + Fitz Roy
11. Lago del Desierto + Glaciar Huemul + rafting
12. Volta para Punta Arenas

Cada etapa marcada como concluída na página fica registrada apenas no navegador (não é salva neste repositório).
